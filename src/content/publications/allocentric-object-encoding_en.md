## About the study

Across four experiments, the study asked how people encode object features while taking another person's visual perspective. The findings support a coarse-to-fine pattern: highly discriminable task-irrelevant features could enter memory together with the target feature, whereas less discriminable features were encoded more selectively. The experiments also distinguished embodied mental transformation from an object-rotation strategy.
